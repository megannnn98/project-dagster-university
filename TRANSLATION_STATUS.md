# Dagster University — русский перевод

Неофициальный перевод [Dagster University](https://github.com/dagster-io/project-dagster-university). Оригинальное авторство и лицензия Apache 2.0 сохранены (см. LICENSE). Переведённые страницы отмечены уведомлением об изменении. Сторонние материалы сохраняют собственные условия использования.

## Статус

| Dagster & dbt | Переведены все 38 отдельных страниц, включая уведомление об устаревании и итоговый проект; с четырьмя общими страницами — 42 страницы оглавления, 8 уроков |

| Testing with Dagster | Все 7 уроков переведены: 28 отдельных страниц и 4 общие страницы, всего 32 из 32, включая дополнительную страницу о философии тестирования |
| AI-driven Data Engineering | Переведены все 8 уроков и итоговый проект: 45 из 45 учебных страниц |

Переведены доступные текстовые страницы всех пяти курсов и все 14 README репозитория. Для каждого курса добавлены русское оглавление сайта и отдельное оглавление для чтения на GitHub: [Dagster Essentials](DAGSTER_ESSENTIALS_RU.md), [Dagster + dbt](DAGSTER_DBT_RU.md), [Dagster & ETL](DAGSTER_ETL_RU.md), [Testing with Dagster](DAGSTER_TESTING_RU.md), [AI-driven Data Engineering](AI_DRIVEN_DATA_ENGINEERING_RU.md). Общие страницы установки и Dagster Skills используются несколькими курсами.

После объединения переводов проверены production-сборка Next.js (226 страниц), ESLint, внутренние ссылки всего сайта и локальные ссылки всех пяти оглавлений GitHub. Страницы четырёх объединённых курсов точно соответствуют содержимому исходных PR; конфликты разрешены в README и этом файле с сохранением навигации, статусов и терминов всех курсов. Исполняемые учебные файлы не изменялись.

Внешние ссылки и выполнение учебных примеров не проверены; независимая редакторская проверка ещё не выполнена. Видео, сторонние иллюстрации, отсутствующие на GitHub уроки и закрытые тесты отдельно не копируются. Локализованы главная страница сайта, метаданные страниц и кнопки блоков кода; установлен язык документа ru. Название кнопки ответа оставлено двуязычным для соответствия инструкциям уроков. Скриншоты, исходные команды, промпты и внутренние инструменты курса не переводились. Новые изменения интерфейса требуют отдельной проверки сборки. Для GitHub Pages подготовлены статический экспорт Next.js, базовый путь репозитория, обработка URL изображений и workflow сборки/публикации с проверкой экспортированных страниц. Источник GitHub Actions нужно включить в настройках Pages; факт публикации и новая сборка пока не подтверждены. Vercel-развёртывание ограничено оригинальным репозиторием.
