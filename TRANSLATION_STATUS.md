# Dagster University — русский перевод

Неофициальный перевод [Dagster University](https://github.com/dagster-io/project-dagster-university). Оригинальное авторство и лицензия Apache 2.0 сохранены (см. LICENSE). Переведённые страницы отмечены уведомлением об изменении. Сторонние материалы сохраняют собственные условия использования.

Переводятся доступные исходные текстовые материалы. Видео, сторонние иллюстрации, отсутствующие на GitHub уроки и закрытые тесты отдельно не копируются. Переведены также README практического проекта и полное оглавление Dagster Essentials. Три страницы установки используются совместно с другими курсами. Переведены все 14 файлов README репозитория, включая README сайта, пяти учебных проектов, каталога запросов и шести примеров dbt; добавлено оглавление Dagster Essentials для чтения на GitHub. Перевод README остальных курсов не означает перевод их уроков. Все 71 маршрут оглавления Dagster Essentials сопоставлены с существующими исходными файлами. Сборка сайта, внешняя проверка ссылок, линтеры и редакторская проверка ещё не выполнены. Публикация на GitHub Pages требует проверки статического экспорта Next.js и настройки базового пути; оригинальный workflow развёртывает сайт в Vercel.
