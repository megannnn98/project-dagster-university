# Dagster University — русский перевод

Неофициальный перевод [Dagster University](https://github.com/dagster-io/project-dagster-university). Оригинальное авторство и лицензия Apache 2.0 сохранены (см. LICENSE). Переведённые страницы отмечены уведомлением об изменении. Сторонние материалы сохраняют собственные условия использования.

| Dagster & dbt | Переведены все 38 отдельных страниц, включая уведомление об устаревании и итоговый проект; с четырьмя общими страницами — 42 страницы оглавления, 8 уроков |

Переводятся доступные исходные текстовые материалы. Видео, сторонние иллюстрации, отсутствующие на GitHub уроки и закрытые тесты отдельно не копируются. Переведены также README практического проекта и полное оглавление Dagster Essentials. Три страницы установки используются совместно с другими курсами. Переведены все 14 файлов README репозитория, включая README сайта, пяти учебных проектов, каталога запросов и шести примеров dbt; добавлено оглавление Dagster Essentials для чтения на GitHub. Перевод README остальных курсов не означает перевод их уроков. Все 71 маршрут оглавления Dagster Essentials сопоставлены с существующими исходными файлами. Для Dagster + dbt добавлены [оглавление для GitHub](DAGSTER_DBT_RU.md) и русское оглавление сайта. В текущем продолжении переведены 33 оставшиеся страницы первого урока, уроков 2–7 и итогового проекта; также переведена оставшаяся английская цитата в первом уроке. Проверены сохранность исходных блоков кода, ссылок, служебных полей module/lesson и тегов Markdoc, а также все 42 маршрута курса. В текст добавлены пояснения к путям проекта, получению артефактов и границам партиций; исходные примеры кода не менялись. Сборка сайта Next.js и проверка внутренних ссылок прошли успешно. ESLint завершился без ошибок. Внешние ссылки и выполнение учебных примеров не проверены; независимая редакторская проверка ещё не выполнена. Публикация на GitHub Pages требует проверки статического экспорта Next.js и настройки базового пути; оригинальный workflow развёртывает сайт в Vercel.
