# Отправка проекта на GitHub

В этом уроке используем GitHub, поскольку Dagster+ имеет встроенную интеграцию с ним для быстрого развёртывания. Аналогичный процесс можно организовать с другой системой размещения репозиториев. Работать через командную строку или GitHub Desktop — на ваш выбор.

У клонированного учебного проекта уже есть история git. Создадим для своей работы отдельный репозиторий:

1. Создайте репозиторий на GitHub и клонируйте его на компьютер.
2. Скопируйте содержимое `project-dagster-university/dagster_university/dagster_and_dbt/` в корень нового репозитория. Например: `cp -R ~/project-dagster-university/dagster_university/dagster_and_dbt/* ~/my-dagster-and-dbt-repo/`.
3. Скопируйте `.gitignore` из репозитория Dagster University, чтобы не закоммитить переменные окружения или большой файл DuckDB. Например: `cp ~/project-dagster-university/.gitignore ~/my-dagster-and-dbt-repo/`.
4. Отправьте код проекта в ветку `main` нового репозитория на GitHub.

{% callout %}
> 💡 **Важно:** убедитесь, что файл `.env` не попал в коммит. Он должен исключаться через `.gitignore`; проверьте это перед отправкой конфиденциальных данных.
{% /callout %}
