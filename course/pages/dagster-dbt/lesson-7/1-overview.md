# Обзор

Теперь у вас есть объединённый проект Dagster и dbt. Вы научились загружать модели dbt как ассеты Dagster, создавать зависимости, добавлять партиции, выполнять пайплайн и отслеживать его через интерфейс Dagster.

В этом уроке подготовим проект к работе в локальном окружении и production. Рассмотрим особенности включения проекта dbt в развёртывание Dagster.

Вы отправите проект на GitHub и настроите CI/CD с учётом dbt. Для примера используем Dagster+, позволяющий пройти единый процесс развёртывания; общие принципы применимы и к другим способам размещения Dagster.
