# Итоговый проект

Вы прошли основную часть курса. Теперь примените полученные знания и продолжите развивать проект Dagster и dbt.

---

## Данные для проекта

Лучше всего использовать данные своей организации. Если такой возможности нет, подойдут дополнительные наборы из [NYC OpenData](https://opendata.cityofnewyork.us/) или [списка публичных API на GitHub](https://github.com/public-apis/public-apis).

Для NYC OpenData авторы рекомендуют набор **311 Service Requests from 2010 to Present** — обращения в городскую службу 311 с 2010 года. Он доступен для скачивания в CSV; подробности — на [странице набора](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2010-to-Present/erm2-nwe9).

Выберите данные, которые вам интересно исследовать. При необходимости продолжайте использовать DuckDB.
