# Обзор

Этот урок подготовит тебя к прохождению остальной части курса. Выбери страницу, соответствующую твоему агенту программирования, и следуй инструкциям по установке и проверке включения скиллов Dagster.

## Совместимость с любым агентом программирования

Курс рассчитан на любой агент, поддерживающий скиллы. Единственное требование — агент должен уметь загружать и использовать [скиллы Dagster](https://github.com/dagster-io/skills). Они предоставляют агенту контекст для создания проектов Dagster с помощью `dg`, соблюдения лучших практик и использования интеграций.

Мы подготовили короткие инструкции по настройке основных инструментов:

- [**Claude Code**](/ai-driven-data-engineering/lesson-3/1-claude): установи скилл Dagster через каталог плагинов.
- [**Codex**](/ai-driven-data-engineering/lesson-3/2-codex): добавь скиллы Dagster через команду `npx skills`.
- [**Cursor**](/ai-driven-data-engineering/lesson-3/3-cursor): добавь скиллы Dagster через команду `npx skills`.
- [**GitHub Copilot**](/ai-driven-data-engineering/lesson-3/4-github-copilot): добавь скиллы Dagster через команду `npx skills`.

Выбери страницу для своего агента и выполни инструкции. Когда скиллы Dagster установлены и включены, можно переходить к уроку 4.

## Недетерминированное поведение

Программирование с ИИ-агентом недетерминированно. Полученный код и команды могут немного отличаться от примеров курса в зависимости от:

- Используемого агента и модели (например, Claude Code с Sonnet 4.6 или Cursor с другой моделью).
- Версии скиллов Dagster.
- Формулировок промптов.

Примеры курса используют Claude Code с Sonnet 4.6. Если ты используешь другой агент или модель, рабочий процесс остаётся прежним, даже если конкретные результаты отличаются.
