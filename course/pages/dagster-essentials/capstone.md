# Итоговый проект

Поздравляем с прохождением курса до этого этапа! Теперь ты применишь полученные знания и создашь собственный проект Dagster.

---

## Данные проекта

Лучший способ применить изученное — использовать данные своей организации. Если это невозможно, можно воспользоваться дополнительными данными [NYC OpenData](https://opendata.cityofnewyork.us/) или [списком публичных API на GitHub](https://github.com/public-apis/public-apis).

Если используешь NYC OpenData, рекомендуем набор **311 Service Requests from 2010 to Present** (запросы в городскую службу 311 с 2010 года). Данные можно скачать в виде CSV, а подробности посмотреть [здесь](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2010-to-Present/erm2-nwe9).

Какие бы данные ты ни выбрал, выбирай то, что действительно тебе интересно!

При необходимости можно продолжать использовать DuckDB.

---

## Требования к проекту

Твой собственный проект должен:

- Создавать пайплайн данных с помощью активов.
- Использовать одну из [поддерживаемых интеграций Dagster](https://docs.dagster.io/integrations), например dbt, Fivetran или Airbyte.
- Содержать ресурс для подключения к источнику данных или хранилищу.
  - Мы предоставляем готовые подключения к большинству популярных облачных хранилищ данных. Однако можно [превратить любое подключение или объект Python в ресурс](https://docs.dagster.io/concepts/resources#using-bare-python-objects-as-resources).
  - Если ты не используешь данные компании, можешь продолжить работу с DuckDB.
- Выполнять преобразования данных с помощью облачных вычислений или вычислений в оперативной памяти.
  - Если тебе интересно использовать dbt, ознакомься с [нашей интеграцией dbt](https://docs.dagster.io/integrations/dbt/reference#loading-dbt-models-from-a-dbt-project)!
- Партиционировать активы и попробовать backfill исторических данных.
- Создавать отчёт на основе данных.
