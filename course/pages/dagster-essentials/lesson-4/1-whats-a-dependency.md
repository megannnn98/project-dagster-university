# Что такое зависимость?

**Зависимость** — это связь между ассетами. Ассеты в этой связи могут быть:

- **Нижестоящими (downstream)** — ассет зависит от другого ассета.
- **Вышестоящими (upstream)** — другой ассет зависит от данного ассета.

Для наглядности рассмотрим часть пайплайна приготовления печенья.

{% table %}

- {% width="60%; fixed" %}
  В этом примере **мука**, **тесто для печенья** и **печенье** — наши ассеты. Разберём, что происходит:

  - Для приготовления **теста для печенья** требуется **мука**. Поэтому **тесто для печенья** является нижестоящим ассетом относительно **муки**, то есть зависит от неё.
  - Для приготовления **печенья** требуется **тесто для печенья**. Поэтому **тесто для печенья** является вышестоящим ассетом относительно **печенья**, то есть его зависимостью.

- ![Пайплайн приготовления печенья с обозначениями типов зависимостей](/images/dagster-essentials/lesson-4/cookie-dependencies.png) {% rowspan=2 %}

---

- {% width="60%" %}
  Другой способ описать зависимости — использовать термины **родитель (parent)**, **потомок (child)** и **предок (ancestor)**. Ещё раз рассмотрим пайплайн приготовления печенья. Поскольку эти термины определяются относительно конкретного ассета, рассмотрим их с точки зрения ассета **печенье**.

  - **Дочерний ассет** является нижестоящим относительно своего _родительского_ ассета. В этом примере **печенье** — дочерний ассет относительно своего родителя, **теста для печенья**.
  - **Предок** — родитель родительского ассета. В этом примере **мука** — предок **печенья**, поскольку **мука** является родителем **теста для печенья**, которое, в свою очередь, является родителем **печенья**.

- ![Обозначения зависимостей относительно ассета «печенье»](/images/dagster-essentials/lesson-4/parent-child-ancestor.png) {% rowspan=2 %}
