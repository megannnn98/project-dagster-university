# Что такое зависимость?

**Зависимость** — это связь между активами. Активы в этой связи могут быть:

- **Нижестоящими (downstream)** — актив зависит от другого актива.
- **Вышестоящими (upstream)** — другой актив зависит от данного актива.

Для наглядности рассмотрим часть пайплайна приготовления печенья.

{% table %}

- {% width="60%; fixed" %}
  В этом примере **мука**, **тесто для печенья** и **печенье** — наши активы. Разберём, что происходит:

  - Для приготовления **теста для печенья** требуется **мука**. Поэтому **тесто для печенья** является нижестоящим активом относительно **муки**, то есть зависит от неё.
  - Для приготовления **печенья** требуется **тесто для печенья**. Поэтому **тесто для печенья** является вышестоящим активом относительно **печенья**, то есть его зависимостью.

- ![Пайплайн приготовления печенья с обозначениями типов зависимостей](/images/dagster-essentials/lesson-4/cookie-dependencies.png) {% rowspan=2 %}

---

- {% width="60%" %}
  Другой способ описать зависимости — использовать термины **родитель (parent)**, **потомок (child)** и **предок (ancestor)**. Ещё раз рассмотрим пайплайн приготовления печенья. Поскольку эти термины определяются относительно конкретного актива, рассмотрим их с точки зрения актива **печенье**.

  - **Дочерний актив** является нижестоящим относительно своего _родительского_ актива. В этом примере **печенье** — дочерний актив относительно своего родителя, **теста для печенья**.
  - **Предок** — родитель родительского актива. В этом примере **мука** — предок **печенья**, поскольку **мука** является родителем **теста для печенья**, которое, в свою очередь, является родителем **печенья**.

- ![Обозначения зависимостей относительно актива «печенье»](/images/dagster-essentials/lesson-4/parent-child-ancestor.png) {% rowspan=2 %}
