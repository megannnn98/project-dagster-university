# Метаданные определения — группы ассетов

По мере добавления новых ассетов сходство между ними становится более заметным. Например, несколько ассетов могут быть связаны с dbt или преобразованием данных, тогда как другие сосредоточены на извлечении исходных данных CSV. Их можно логически объединить в **группы ассетов**.

Группа ассетов позволяет поддерживать порядок среди ассетов и упрощает наблюдение за ними в интерфейсе. Кроме того, группы упрощают выбор ассетов для задания, поскольку вместо перечисления отдельных ассетов можно сослаться на группу.

В Dagster группы ассетов можно задавать двумя способами:

- Для всех ассетов модуля.
- Для отдельных ассетов.

---

## Что нужно учитывать

При добавлении ассетов в группы помни:

- Если ассет не входит ни в одну группу, он будет помещён в группу с именем `default`.
- Один ассет может одновременно принадлежать только одной группе.

---

## Группировка отдельных ассетов с помощью декоратора

Для отдельных ассетов можно задать группу с помощью параметра `group_name` декоратора ассета. Например:

```python
# src/dagster_essentials/defs/assets/trips.py
import dagster as dg

@dg.asset(
    group_name="raw_files",
)
def taxi_zones_file() -> None:
    """
      The raw CSV file for the taxi zones dataset. Sourced from the NYC Open Data portal.
    """
    raw_taxi_zones = requests.get(
        "https://community-engineering-artifacts.s3.us-west-2.amazonaws.com/dagster-university/data/taxi_zones.csv"
    )

    with open(constants.TAXI_ZONES_FILE_PATH, "wb") as output_file:
        output_file.write(raw_taxi_zones.content)
```

В этом примере ассет `taxi_zones_file` входит в группу `raw_files`.

---

## Группы ассетов в интерфейсе Dagster

Когда группы определены, страница **Global Asset Lineage** помещает их участников в отдельные серые прямоугольники. Например, на следующем изображении показаны три группы:

- `raw_files`, которая сейчас содержит только `taxi_zones_file`.
- `metrics`, включающая все ассеты подмодуля `metrics`.
- `default`, содержащая ассеты, пока не входящие в другие группы. **Примечание:** если другие группы не определены, группа `default` здесь не отображается.
