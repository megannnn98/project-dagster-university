# Практика: группировка ассетов

Чтобы закрепить знания о группах ассетов, организуй ассеты своего проекта следующим образом:

- **С помощью декоратора ассетов**:
  - Добавь `taxi_trips_file` в группу `raw_files`.
  - Добавь ассеты `taxi_zones` и `taxi_trips` в группу `ingested`.
  - Добавь ассет `adhoc_request` в группу `requests`.

---

## Проверь свою работу

Созданные группы ассетов должны выглядеть примерно как код, скрытый под переключателем **View answer**. Нажми на него, чтобы открыть ответ.

### Для способа с декоратором ассетов:

Ассеты групп `raw_files` и `ingested` должны выглядеть так:

```python {% obfuscated="true" %}
@dg.asset(
    group_name="GROUP_NAME"
)
def name_of_asset():
```
