# Анализ использования ресурсов через интерфейс Dagster

Ранее мы кратко упоминали вкладку **Resources** на странице **Overview**. Мы уделили ей немного времени, поскольку до этого она не приносила пользы. Теперь, когда ассеты используют ресурс базы данных, с её помощью можно подробнее изучить свои ресурсы.

{% table %}

- Открытие вкладки Resources

---

- {% width="60%" %}

  1. В интерфейсе Dagster нажми **Deployment**, затем выбери расположение кода `dagster_essentials`.
  2. Далее перейди на вкладку **Definitions**, затем выбери **Resources** на боковой панели навигации.
  3. В столбце **Name** нажми на `database`. Теперь, когда ассеты обновлены для использования ресурса `database`, столбец **Uses** показывает **4**.

- ![Вкладка Resources для расположения кода dagster_university](/images/dagster-essentials/lesson-6/resources-tab-2.png) {% rowspan=2 %}

{% /table %}

{% table %}

- Просмотр сведений о ресурсе

---

- {% width="60%" %}
  Эта страница содержит подробные сведения о ресурсе, например его тип и конфигурацию.

- ![Вкладка Configuration страницы сведений о ресурсе](/images/dagster-essentials/lesson-6/resource-details.png) {% rowspan=2 %}

{% /table %}

{% table %}

- Просмотр использования ресурса

---

- {% width="60%" %}
  Нажми вкладку **Uses**, чтобы просмотреть информацию об ассетах, использующих этот ресурс.

  Эта страница важна для понимания того, какие ресурсы доступны и как они используются. Типичные сценарии применения этой информации:

  - Определение возможных последствий миграции базы данных.
  - Исследование роста стоимости сервисов и поиск причины увеличения расходов.

- ![Вкладка Uses страницы сведений о ресурсе](/images/dagster-essentials/lesson-6/resource-uses-tab.png) {% rowspan=2 %}

{% /table %}
