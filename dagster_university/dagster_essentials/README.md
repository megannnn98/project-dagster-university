# Dagster Essentials

## Обзор

Изучи основы Dagster — платформы на Python, позволяющей создавать надёжные пайплайны данных, готовые к эксплуатации. В ходе курса ты научишься представлять пайплайн данных через создаваемые им ассеты данных и управлять выполнением собственного пайплайна с помощью Dagster.
