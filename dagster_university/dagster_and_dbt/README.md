# Dagster и dbt

## Обзор

Научись интегрировать и оркестрировать проекты dbt с помощью Dagster. Ты загрузишь модели dbt в Dagster как ассеты, построишь зависимости и подготовишь проект к развёртыванию в рабочем окружении.
